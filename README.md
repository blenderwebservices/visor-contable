# Visor Contable

Visor Contable es una plataforma web diseñada para la gestión, distribución y visualización segura de documentos contables y reportes empresariales. 

El sistema está dividido en dos grandes secciones para atender las necesidades tanto del equipo gestor como del cliente final. A continuación se detalla la funcionalidad de la aplicación dirigida a los usuarios finales:

## 1. Usuario Administrativo (Gestor)
El Usuario Administrativo tiene el control total sobre la plataforma a través de un panel de control exclusivo (`/admin`). Sus funciones principales incluyen:

* **Gestión de Empresas (Grupos):** Creación, edición y administración de las distintas empresas o grupos corporativos que utilizan la plataforma.
* **Gestión de Usuarios:** Creación de cuentas para clientes y personal, así como la asignación directa de cada usuario a su respectiva empresa (grupo).
* **Gestión de Carpetas:** Creación de una estructura organizativa a la medida para mantener los documentos ordenados lógicamente.
* **Gestión de Archivos y Documentos:** Capacidad para subir documentos, asociarlos a carpetas específicas y restringir su visibilidad para que únicamente la empresa o cliente correspondiente tenga acceso a ellos.
* **Supervisión Centralizada:** Control y monitoreo de la plataforma para asegurar que la información contable sea distribuida correcta y seguramente a cada cliente.

## 2. Usuario de la Aplicación (Cliente Final)
El Usuario de la Aplicación es el cliente, directivo o usuario final que accede al portal (`/app`) para consultar su información. Sus funciones se centran en la lectura y obtención de documentos:

* **Acceso Personalizado:** Al iniciar sesión, el usuario entra a un entorno enlazado directamente a su Empresa/Grupo, garantizando la privacidad de su información.
* **Exploración de Documentos:** Navegación intuitiva por las carpetas y estructuras de archivos que el Usuario Administrativo ha habilitado para su empresa.
* **Visualización:** Vista previa y lectura de los documentos contables, reportes y archivos digitales directamente en la plataforma.
* **Descarga e Impresión:** Capacidad para descargar los archivos a su dispositivo local y realizar impresiones de manera sencilla cuando se requiera respaldo físico o análisis offline.
* **Acceso Directo al Frontend:** Navegación fluida hacia el portal público o área principal (Frontend) con un solo clic desde su perfil.
